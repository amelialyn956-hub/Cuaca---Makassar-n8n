# Cuaca Makassar - n8n

→Project ini ambil data cuaca Makassar tiap pagi pake n8n, simpan ke Google Sheets.

 Cara Kerja:
1. Schedule Trigger - jalan tiap pagi
2. HTTP Request - ambil data dari Open-Meteo
3. Google Sheets - simpan hasilnya

Cara Pakai:
1. Download file .json ini
2. Buka n8n > Import > pilih file ini
3. Sambungin Google Sheets kamu
4. Aktifin workflow-nya
